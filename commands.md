## S'more commands but VIM centric
- i for insert, begin writing here at cursor
- ESC command mode - navigation with keys
- hjkl - allows one cursor movement in those directions
- x - delete a character - this while in command mode
- dw - delete a word
- dd - delete an entire line
- yy - yank or cut a line out
- u - undo last command / edit - this can be repeated
- G - go to end of document/file
- gg - go to beginning of file
- e - go to end of word
- b - go to beginning of word
- A - append - i.e. start writing at the end of this line - faster than typing 'i'
